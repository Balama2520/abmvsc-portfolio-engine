Launch your website

Four steps from here to a live site. No code, no hosting bill, no build tools.

  1. Download your config.js

    Everything you just typed is packed into that one file.

  2. Take your own copy of the engine

    Open the template repository and click Use this template, or clone it.

    https://github.com/Balama2520/abmvsc-portfolio-template
    git clone https://github.com/Balama2520/abmvsc-portfolio-template.git my-site
  3. Drop in the config.js you downloaded

    Replace the file the engine shipped with. Both index.html and studio.html now read your details.

    The file in the repo is ABMVSC's demo data — replacing it is the step that makes the site yours.

  4. Put it online — free

    Drag your project folder onto Netlify Drop, or push to GitHub and switch on Pages. Live in about a minute.
